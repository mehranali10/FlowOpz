# FlowOpz — GHL Landing Page Design

Design for the FlowOpz landing page, built to be recreated in the GoHighLevel page builder with native elements plus one Custom CSS paste.

| File | What it is |
|---|---|
| `index.html` | Design preview. Open it in a browser and resize to check desktop, tablet and mobile. |
| `ghl-custom-css.css` | The only code. Paste it into GHL: Page > Settings > Custom CSS. Adds smooth scrolling, the page-load animation, hover effects and responsive type sizes. |
| `GHL-BUILD-GUIDE.md` | Step-by-step build guide (Roman Urdu): sections, rows, columns, sizes, custom classes and entrance-animation delays. |

Content is taken from [flowopz.com](https://flowopz.com).
